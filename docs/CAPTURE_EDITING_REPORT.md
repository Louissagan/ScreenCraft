# 0.7.0 截图绘制结构与文字/说明交互

日期：2026-11-04。依据用户提供的 4 张照片和 5 项反馈推进。未操作真实桌面、截图屏幕、注册实际快捷键或更改运行中的旧版。

绘制改为固定全屏 Canvas：冻结底图保持物理像素坐标，裁剪只是逻辑范围，尺寸、边框与八个控制点由同一画布绘制。原来移动范围会移动裁切画布及控制点 HWND，现在不再移动这些 HWND。工具条/属性面板是画布子控件，旧/新覆盖区显式失效；压暗底图只缓存一次，背景用像素覆盖而非重复 Alpha 混合，跳过普通文件编辑器的缩放视图/阴影路径。冻结识别窗口在编辑关闭后才关闭，减少先关闭截图层再构造编辑器的桌面空档。详细属性按需创建。

属性面板改为共享圆角分组、选择器和开关；取消整条红色按钮，描边、文字与底色分别用色点按钮表示。原有线型、透明度、几何、序号、图层、删除功能保留。工具条直接提供可变圆角滑块，默认范围 0–200，已有较大值会扩展，详细面板可精确输入至 1000。

文字编辑原先有 `selected==null || box!=null` 的拒绝条件，说明绘制和输入预览还强制加白底；这些路径已调整。输入期间改变字号/颜色/填充会即时更新，属性控件取得焦点不再结束输入。文字和说明支持透明底或色底白字；没有默认白色说明框。绘制前的默认说明样式和已选说明都保留圆点颜色/大小；调色板、更多颜色和原图取色均按当前文字角色设置。说明字体与圆点字体分离，独立文字色/字号持久化为可选字段，旧工程字段缺失时回退到旧字体/文字色。

说明框拖动只改 NoteOffset；拖动圆点或云线主体时补偿 NoteOffset，使说明框保留原位置，连接线随动。选中外框以当前部分为界，不再用圆点与说明框的联合大框画过长边线。输入时继续显示圆点/云线主体，说明输入按固定说明宽度换行；滑块焦点用滑块本身的蓝色边缘提示，去掉长矩形焦点框。
