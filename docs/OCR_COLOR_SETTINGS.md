# OCR 语言及 RGB 输出设置（未打包）

> 此修改现已收录于 0.9.3；下文保留开发阶段的验证记录。见 [发布说明](RELEASE_0.9.3.md)。

2026-11-07。

OCR 语言通过 Windows 本地 OCR 引擎检测，设置页仅提供“自动选择”和检测到的已安装语言，不再接受任意文本。异步检测不阻塞设置窗口，检测失败或无可用语言时禁用语言选择并提示安装。已有或导入的语言标签按实际支持项解析；不支持时提示改选自动。OCR 结果窗口也不再把不支持的历史语言加入菜单。

RGB 是色彩模型，六位十六进制与十进制三通道是同一 RGB 颜色的不同表示：

| 设置选项 | 示例 | 保存的兼容值 |
| --- | --- | --- |
| RGB · 三通道数值 | `rgb(255, 128, 64)` | `RGB` |
| RGB · 六位十六进制 | `#FF8040` | `HEX` |
| HSL · 色相／饱和度／亮度 | `hsl(20.1, 100%, 62.5%)` | `HSL` |

实时输出示例随选项和大小写变化；大小写开关仅作用于六位十六进制。保留原配置键，取色复制流程无需迁移。

验证：完整回归 **230 PASS / 0 FAIL**。新增检查覆盖已安装语言及别名、不可用历史语言、缺少引擎、两种 RGB 表示的示例与保存。本机原生能力探针读到 `en-US`、`zh-Hans-CN`，验证下拉选择后保存 `en-US` 与 `HEX`；没有修改用户配置或读取剪贴板／桌面。探针的 PrintWindow 图像为空黑，未用于实屏视觉验收；离屏共享绘制只用于检查控件位置。

证据：[测试与能力探针结果](evidence/automated/ocr-color-settings/)。源码：`tools/OcrSettingsProbe.cs`、`tests/OcrColorSettingsTests.cs`。未生成新发布包，运行中的旧版本未替换。
