# ScreenCraft 0.9.3 开发预览

2026-11-07。汇总自 0.9.2 后各轮反馈，供实际使用测试。

## 启动

先从 Windows 右下角旧版托盘选择“退出”，再解压便携 ZIP，运行其中的 `ScreenCraft.exe`。保留完整目录，不要只复制 EXE。托盘或设置标题应显示 **0.9.3.0**。便携版使用旁边的 `Data` 保存偏好；若需原有便携配置，在退出旧版后复制旧目录的 `Data` 到新目录。每用户 MSI 为另一安装方式，默认不自动启动应用。

## 本次合入

- Shift／Ctrl 多选、组合编辑与撤销、八点缩放。
- 所选底色＋白字文字框；实心点、数字点、云线共用注释参数，数字位于点上，点大小与引线粗细联动。
- QQ 常用色和分析图两套预制；内置色谱、RGB、HEX、原图取色，替代系统调色盘。
- 工具栏顺序／显隐配置，隐藏工具仍保留参数；圆角透明 PNG 导出与工程保存。
- 修复设置打开时吞掉截图快捷键，截图临时隐藏设置后保留草稿。
- OCR 只列出本机引擎支持语言；明确区分 RGB 六位十六进制与三通道数值，并显示示例。
- 窗口、客户区、面板、按钮多层吸附，滚轮切换范围；保留手动框选。
- 删除“关于”页设计参考说明。

## 建议先试

1. 打开设置的常规／截图页，按区域截图快捷键，确认能启动截图；在快捷键输入框中同一按键应被录入。
2. 在普通应用窗口内移动鼠标，确认不同区域吸附；滚轮切换更大／更小范围，再试直接拖框。
3. 创建两个矩形，用 Shift／Ctrl 多选；拖边中点、一起移动和改色，再撤销。
4. 输入文字并切换颜色；提交、重编辑应始终保留所选底色与白字。试三种注释来源、点大小、引线及文本宽度。
5. 选择两套预制色和自定义色，调整工具顺序；保存圆角 PNG，检查透明四角。
6. 在 OCR 与取色中选择已安装语言，核对两种 RGB 输出示例及实际复制值。

完整自动回归 233 项；另有原生合成窗口探针覆盖编辑、设置焦点、语言能力读取和四层范围。包内源码需通过独立解压重建与 MSI 结构检查后交付。

范围限制：UIA／原生控件未开放的自绘画面与图片内部区域未做视觉分割；不同应用的吸附覆盖仍需实测。最新实屏快拖复测曾因窗口遮挡中止，不能据此声称所有残影问题解决。详见 [已知限制](KNOWN_LIMITATIONS.md)。
