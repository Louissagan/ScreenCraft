# 已知限制与未完成验收

当前源码为 **0.10.1 截图闪烁修复开发预览**。旧 27 个运行时模块已替换，完整自动检查 262 项通过（0.10.0 的 257 项及新增 5 项）；新增内核测试见 [重写记录](CORE_REWRITE.md)。此前 0.9 系列的实屏与安装包记录仅是历史证据，不代表本版已重新通过相同验收。

- 本版已测合成输入、隐藏原生窗口重绘、资源释放与本地 OCR 合成样本。截图交接另有 3 次自有实窗口、113 帧无异常空白色帧的限定采样，见 [0.10.1 修复记录](RELEASE_0.10.1.md)。真实混合 DPI、多显示器、自动滚动、动态浮动网页内容和持续快拖仍需重新验收。
- 新滚动匹配器拒绝无法唯一确定的重复纹理；可能需要减小滚动步长或改用手动截图。页面固定头尾与侧栏有合成覆盖，动态悬浮控件的移除效果尚未完整验收。

- 多层吸附已验证按钮、面板、客户区、整窗；任意图片内部区域、自绘页面及不同浏览器／Electron 的覆盖未完整验收。没有开放控件边界时保留整窗和手动框选。
- 最新实屏快拖探针因测试窗口遮挡中止；0.9.2 的实屏通过记录不能视为本版重新实测。最终坐标、取消、撤销与重绘自动回归通过，持续快拖残影仍需实机复核。

- 快速拖动测试使用合成底图和定向窗口鼠标消息，实测显示比例为 125%。混合 DPI 双屏实拖、高刷新率设备和用户照片中相同的持续叠框条件仍待复核。
- StyledMenu 提前释放、按钮额外边线与设置重绘残留有修复前后的自动化证据；真实用户鼠标连续展开/换色与 DWM 边角仍 NOT RUN。
- 0.9 MSI 已生成。隔离产品的静默安装、升级、卸载 6 项 PASS；生产向导、真实标准账户令牌、实际安装实例退出、用户自启/注销重登及跨机便携迁移 NOT RUN。隔离包禁用了生产清理/退出自定义动作；对应边界用假适配和成品数据库检查，不能冒充生产卸载全流程通过。
- MSI 默认不运行应用、不启用自启、不删除配置/用户图片。主动清理参数仅作用自有历史缓存；不删除用户保存目录。未代码签名，不能保证 SmartScreen 或组织策略放行。
- 主应用依赖目标 Windows 已有 .NET Framework 4.8；没有要求 SDK。MSI 首次构建需要取得固定哈希的 WiX 工具 ZIP；不在目标用户运行时下载。
- 贴图旋转/翻转是非破坏视图，PNG/复制按方向输出，sccraft 保留方向。重新编辑使用原图坐标，应用回贴图后保留方向；这不等于任意标注对象旋转。
- Ctrl 拖出已生成真实 PNG/FileDrop 数据并接上 OLE；资源管理器、微信、Office 等接收结果及缓存清理时序的真实 GUI NOT RUN。中转 PNG 保留至少到下一次一天后的清理，避免接收方延迟读取失败。
- 画板支持 100 个图像元素、90° 旋转、边缘/中心吸附和完整内容导出；任意角度、等间距分布命令和多选尚未齐全。源资源含撤销共 6400 万像素；导出也受 6400 万像素及单边 32767 限制，超限报错不截断。真实拖动、未保存提醒和混合 DPI 未实测。
- 美化提供纯色/12 种渐变、边距/圆角/采样边框/阴影/比例，已测导出与工程往返；桌面/自选壁纸库、任意外框颜色及完整参考布局仍有差距。
- 本地文件编辑工具条与管理/历史界面已使用共享图标和控件，仍不是截图浮条的完全同构布局；精确属性在右侧。普通文件编辑器关闭尚无未保存提醒，画板已有。
- 磨砂只采样冻结截图浮条，不是实时桌面或 macOS 系统玻璃。输入中的原生 TextBox 使用当前标签底色；长说明超过选区会被导出裁剪。
- 历史默认关闭；只保存完成图的自有副本，手动导出不作为历史删除目标。scboard/sccraft 工程保留原图，请分享扁平 PNG。日志不记录 OCR/剪贴板内容。
- 本地 OCR 的新调用代码已通过中英文和长图合成样本，仍有 OCR-001：孤立英文短行可能漏识别，应校对并重试。语言包安装、断网和真实剪贴板未验收。没有云 OCR 或已配置翻译服务。
- 垂直滚动拼接已有固定头尾/侧栏、色差/亚像素、部分失败和分段测试；Chrome/Edge/PDF/Win32 实测 NOT RUN。上限 30000 行/4000 万像素，达到后只保留已捕获部分，横向长图尚未实现。
- QR、任意对象旋转、复杂折线箭头、完整备注/计数侧栏、局部放大工具、图片/Logo 水印、实况 OCR 选字、完整工作流与拖放架、AI 擦除/去背景等尚未齐全。录屏/GIF 按当前优先级后置。
- 深浅主题/高对比和多语言界面尚未全部统一，中文优先。
