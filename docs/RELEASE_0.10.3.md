# 0.10.3 系统通知、色盘与线宽输入

2026-11-10，开发预览版。

- 启动和重复打开统一使用 Windows 系统通知，移除自绘启动窗口。常规设置仍可关闭启动通知，配置错误继续通过同一系统通知渠道提示；有配置警告时不再同时发送普通启动通知。
- 已启用的标准 ScreenCraft 自启项指向旧版或移动前的位置时，新版启动会更新到当前程序。不会启用原本关闭的自启项、接管带额外参数的自定义命令，或将较新版本的路径换成旧版本。
- 预设色盘扩充为常用标注 16 色、分析图 12 色。保留用户提供的原有颜色，增加互补色与低饱和度分析色。仍支持色相面板、RGB、HEX 和原图取色。
- 新笔画线宽默认 4px，快捷滑块范围 1–24px。滑块旁可直接输入小数；Enter 确认，Esc 放弃当前输入，避免触发截图完成或关闭。
- 截图标注和文件编辑器使用同一套尺寸规则。字号、马赛克、聚光灯和标记大小继续使用各自范围；云线边界也有直接数值输入。旧工程中超过常用范围的线宽保持原值。

验证：**291 项自动检查通过**。覆盖通知回调、中文及空格路径自启迁移、不启用关闭项、不替换较新项、数值输入及取消、旧工程宽线保留、参数单位切换和色盘点击。预设与自定义色盘在 100%、125%、150%、200% 完成离屏绘制检查，截图和文件编辑器的数值控件完成离屏预览。

本版生成便携 ZIP、每用户 MSI、独立 EXE 和源码 ZIP。包内版本、SHA-256、安装器结构和源码独立重建由打包验证脚本检查。系统通知的实际显示位置、持续时间及免打扰行为由 Windows 管理；本次自动检查没有向用户桌面发送真实通知或改写用户自启项。

测试新版前先退出旧版托盘。安装版沿用当前用户的设置；便携版使用解压目录中的独立 Data 设置目录。
