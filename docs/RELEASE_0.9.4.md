# ScreenCraft 0.9.4 开发预览

2026-11-08。在 0.9.3 全部修改基础上修正自动保存目录。

- 启用“复制并自动保存”或“仅自动保存”后，默认直接存入当前用户的系统桌面。
- 目录从 Windows `Environment.SpecialFolder.DesktopDirectory` 获取，遵循桌面重定向，不拼接 `C:\Users\用户名\Desktop`，也不依赖桌面的显示名称。
- 设置显示实际桌面路径；保存默认设置时使用空值表示“当前用户桌面”，防止便携版／导出配置把一个人的用户名作为另一个人的默认目录。清空目录同样恢复系统桌面，自定义目录继续保留。
- Unicode 文件流和既有长路径处理用于目录创建、PNG 保存、读回和重名避让。测试在隔离目录模拟中文用户名、空格、OneDrive 目录与超过 260 字符路径，未修改 Windows 用户或桌面配置，也未向用户真实桌面写入测试图片。
- 保持“完成后动作”的现有选择。默认仍为复制；本次仅改变自动保存所用目录，不强行启用自动保存。

完整回归 237 项，包括四项桌面保存检查。若系统未返回桌面目录，会提示用户指定保存目录，不悄悄写到程序目录。

先退出旧版托盘，完整解压新便携包后运行其中的 `ScreenCraft.exe`；设置版本应显示 **0.9.4.0**。已手动指定的保存目录不会被改为桌面。

其余功能、测试重点与范围限制见 [0.9.3 说明](RELEASE_0.9.3.md) 和 [已知限制](KNOWN_LIMITATIONS.md)。
