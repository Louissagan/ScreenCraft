# ScreenCraft 0.9.1 界面与交互审查

2026-11-05 · Windows x64

## 两张照片对应的问题

第一张照片中的白框与浮条一起移动。0.9.0 把整张桌面放在一块固定画布上，但主工具条、属性条及其按钮仍是独立的 Windows 子窗口。每次鼠标移动都会重新测量、移动这些窗口，重算两块磨砂材质，再刷新画布。旧版还忽略了松手事件里的最终坐标。本机可见窗口复现了拖动积压与终点错误。静止后强制重绘的画面与原画面一致，照片里那种密集叠框没有稳定复现。

0.9.1 在按住选区控制点、尺寸标签或重新框选期间收起浮条和精确属性面板。冻结画面、边框、控制点、尺寸和参考线继续随指针更新。松手后按最终坐标放置浮条，整个拖动只占一次撤销。失去鼠标捕获或按 Esc 会回到原位置，也会保留之前的重做记录。

第二张照片里的图标原本就由矢量路径绘制，但按钮和图标分别固定在 34 和 22 个物理像素，工具栏用到的缩放函数也忽略了目标显示器。细小的字体图标和密集的马赛克格在这个尺寸上尤其难认。属性条还设了固定宽度上限，使线宽滑块被挤到第二行。

新版按选区所在显示器的比例布置工具栏，按按钮实际尺寸绘制图形。重画了画笔、文字、批注、马赛克、撤销、重做、贴图、调节和更多等符号。完成与取消固定在主条末端。属性名称和数值放在滑块旁，宽度足够时同排，窄屏换行。截图范围和导出仍以源图物理像素计量。视觉参考来自官方中文文档的工具栏原图。[1Capture 开始截图](https://1capture.com/docs/cn)

## 同机拖动对照

相同 960 × 540 合成底图、相同初始选区、同一台 Windows 电脑和 125% 显示比例。探针向真实可见的生产 Canvas 窗口发送按下、120 次移动及松开消息。每 12 次让窗口处理一次排队消息。计时包含拖动中第一帧的读取与保存。它衡量这组操作的处理时间，物理鼠标延迟和刷新率需单独测量。

| 项目 | 0.9.0 | 0.9.1 |
|---|---|---|
| 120 次快速移动 | 9,842 ms | 153 ms |
| 松手应得到 690 × 240 | 实际 442 × 333 | 实际 690 × 240 |
| 拖动中浮条 | 跟随选区逐次重新定位 | 收起，松手后恢复 |
| 画面与强制重绘比较 | 松手后差异 0 像素 | 拖动中采样帧及松手后采样帧各差异 0 像素 |

旧版及新版画面都来自实际可见窗口。底图由测试生成。只在探针创建的窗口内临时允许读取测试画面，发行程序继续使用截图排除设置。[旧版工具栏](evidence/automated/ui-0.9.1/toolbar-0.9.0.png) · [拖动中](evidence/automated/ui-0.9.1/drag-0.9.1.png) · [新版工具栏](evidence/automated/ui-0.9.1/toolbar-0.9.1.png) · [实测记录](evidence/automated/ui-0.9.1/visible-probe.txt)

## 按工作流程审查

| 界面 | 发现与处理 | 验证范围 |
|---|---|---|
| 框选、原位标注、尺寸标签 | 修复上述拖动路径。首次框选和标注对象也读取松手坐标。选区外衬和十字线减轻，保留可调边框。 | 可见窗口快速调整选区。初选、对象、撤销和导出的覆盖见自动化记录。 |
| 浮动工具条、属性条、颜色面板、详细属性 | 图标改为按实际尺寸绘制，滑块显示蓝色已用区段。选中工具向辅助功能接口报告按下状态。精确面板仍有较多与当前工具关联较弱的字段。 | 工具栏实屏取帧，100%、125%、150%、200% 布局与裁剪回归。颜色和精确面板有隐藏控件测试。读屏软件待测。 |
| 本地文件编辑、贴图再编辑 | 共享新图标。撤销和重做跟随可用状态。马赛克快捷滑块原先改线宽，现改色块大小。裁剪和实色遮盖收起无关快捷属性。 | 可见文件编辑器及对象模型回归。文件编辑器关闭前的未保存提醒仍是缺口。 |
| 独立贴图、贴图管理 | 贴图缩放补上松手坐标。列表刷新包含垂直翻转状态，空列表的说明居中，操作禁用。 | 可见管理窗口和隐藏贴图窗口回归。跨屏置顶与向微信、Office 拖出待实测。 |
| 拼图画板 | 空画板禁用撤销、重做和需要选图的命令。选中图片后恢复。移动、调整大小和平移读取松手位置，拖回起点也可正确落位。 | 可见空画板，合成素材的移动、缩放、吸附和撤销测试。 |
| 历史记录 | 空状态区分历史已开启与已关闭，操作说明放在预览区。空列表禁用清理。 | 可见空状态、记录开关及多行列表回归。 |
| 设置七个分区、工具栏配置 | 压缩窗口时七个分区按可用宽度分配。快捷键继续用系统键盘录入。工具排序列表的原生勾选框与其余设置仍有视觉差异。 | 七页及独立工具栏配置均查看了可见窗口客户区。 |
| OCR、取色 | OCR 的复制、重试和取消采用共享按钮，自动语言用中文显示。文本区域保留可编辑、选择及复制。取色面板的 HEX 输入与色点同时保留。 | OCR 可见窗口与状态控件测试。取色、剪贴板失败处理按自动化结果，未测本轮跨应用粘贴。 |
| 图片美化、文字水印、文字备忘 | 三者使用既有分组与色点控件。水印主要靠参数输入，应用前缺少与背景美化相同的成品预览。 | 三个可见窗口及合成图的导出测试。 |
| 托盘、弹出菜单、启动提示、滚动截图 | 托盘和通用菜单沿用共享图标。启动提示带快捷键。滚动截图另有一套操作条，交互和视觉仍需单独在目标应用中复核。 | 菜单、提示用隐藏窗口或合成渲染。长图验证覆盖拼接算法，真实浏览器滚动、焦点恢复和多屏切换仍待实测。 |
