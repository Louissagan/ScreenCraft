# 1Capture 更新日志核对

核对日期：2026-11-05。来源：[官方中文更新日志](https://1capture.com/docs/cn/changelog)。网页工具读取失败后，直接通过 HTTPS 读取公开页面（HTTP 200），完整检查可见正文中的 **19 个版本**，从 2025-03-08 的 1.0.0 到 2026-10-22 的 1.12.0。没有把脚本/导航数据中出现的其他版本号当成正文已发布记录。原始页面仅在本地 `docs/reference/` 留存，不随源码包分发。

## 0.8 基准结论（0.9 更正见下）

本轮补的是已点名的日常标注和备忘能力，并修正菜单释放崩溃。**仍不是 1Capture 全功能一比一成品。** QR、横向长图、AI 擦除/去背景、录屏/GIF、拖放架、通用旋转、图片水印和完整美化/历史/画板均不能写成完成。

Windows 原任务书的普通用户权限、便携、用户级安装、自启、热键冲突、混合 DPI 和 AC-01~30 仍保留。0.8 时用户级安装包尚未生成；0.9 已生成并完成隔离 MSI 引擎集成，真实 GUI 继续 NOT RUN。测试明细、离屏证据与源码包独立重建日志见 `POPUP_CAPTURE_FEEDBACK_REPORT.md`。
