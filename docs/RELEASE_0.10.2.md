# 0.10.2 标注旋转与闭合手绘

2026-11-10，开发预览版。

- 调整绘图顺序采用 Adobe Illustrator 的 Windows 快捷键：`Ctrl+]` 前移一层、`Ctrl+[` 后移一层，加入 `Shift` 后分别置顶、置底。截图标注、图片编辑器和画板使用相同组合键。多选标注调整顺序时保留内部顺序，到达边界时不会生成空的撤销记录。
- 画笔属性增加“自动闭合手绘线”。松手后连接首尾，可使用平滑线和半透明填充；填充跟随所选颜色。闭合与曲线箭头互斥，原始节点仍可编辑。不开启时继续使用开放线条。
- 选中标注后可拖动选框上方圆点旋转，按住 `Shift` 吸附到 15°。二级工具条提供顺时针 90°，详细属性可输入角度。支持多选一起旋转；旋转后仍可点选、移动和使用原有控制点缩放。
- 旋转与闭合写入 `.sccraft` 工程，撤销、重做、裁剪后的导出和重新打开工程均保留。旧工程缺少这两个字段时按 0°、不闭合读取。旋转后的文字在输入期间横排编辑，完成后恢复所设角度。
- 马赛克和模糊旋转的是作用范围，采样位置仍对应原图；聚光灯的开孔也跟随角度。
