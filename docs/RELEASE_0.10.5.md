# ScreenCraft 0.10.5

修正进入截图和确认退出时，全屏窗口可能提前露出空白画面的问题。框选和标注窗口现在会先绘制完整首帧，等 Windows 桌面合成器接收画面后再显示。点完成后，程序先从屏幕移除编辑窗口，再拆除控件。Windows 把焦点还给旧框选窗口时，该窗口也已经隐藏。

在 2560 × 1440 的同一块屏幕上，用 0.10.4 和 0.10.5 分别连续执行三次框选和确认。测试实际调用“完成并复制”，在内存中检查交付图片，保留系统剪贴板。两版都观察到模态返回后旧窗口再次收到激活事件。新版在首帧绘制前、编辑窗口关闭时以及旧窗口再次激活前均已设置合成器遮蔽。

新版在首帧故意延迟 90 毫秒的测试中采样 199 次，没有检测到异常颜色。该组使用合成底图，暂时允许读取测试浮层。另以发行配置的截图排除策略重复三次，确认窗口正常显示、遮蔽和关闭，输出图片内容与尺寸正确。完整回归 306 项通过。

这次软件采样也未稳定复现旧版的整屏白闪。显示器实际输出、混合 DPI 和不同刷新率仍需实机复测。测试时先退出旧版托盘，再运行新版，用原来的快捷键截图并点工具栏勾号确认。
