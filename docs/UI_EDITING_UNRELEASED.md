# 标注交互与颜色修改（未打包）

> 此修改现已收录于 0.9.3；下文保留开发阶段的验证记录。见 [发布说明](RELEASE_0.9.3.md)。

2026-11-05。依据用户提供的 QQ 截图、分析图配色及本轮标注问题修改工作区。没有生成安装包、便携包或源码包，没有替换正在运行的程序；`dist/0.9.2` 保留原版本。

## 本轮行为

- **多选**：Shift／Ctrl 单击增减对象，Ctrl+A 选择全部；组合移动、八点缩放、改色、复制、删除、方向键移动及层级调整共用撤销。截图与文件编辑器使用同一画布逻辑。
- **八点编辑框**：矩形等区域、文本框及多选框均增加四边中点，边中点只调整对应方向。直线／箭头保留端点与曲线控制点；圆点保持圆形。
- **统一文字模式**：颜色用于文本框底色，文字固定白色；输入、选色、提交、重新编辑均保持这一模式。快捷面板和详细属性只留一个“颜色”入口。几何半透明填充仍跟随轮廓色，保留透明度。
- **三种注释来源**：实心点、数字点、云线。数字在来源点上；实心点和数字点共用大小设定，引线宽度为点直径的 1/12（最小 1px）。三种来源共用字号、文本宽度和白字色底文本框；切换来源保留已有文字和文本框位置。旧工程的显式数字牌字段保留读取兼容，新面板不再提供该模式。
- **二级菜单**：按来源、颜色、来源尺寸、字号、文本宽度分组；窄屏换行时名称与滑块保持在一起。取消旧的固定 728 逻辑像素上限，在屏幕可用范围内按内容排布。
- **工具栏**：默认展开常用绘图与效果工具；“更多 → 工具栏显示与排序”支持调整前后顺序、显隐和工具键，保存后立即更新截图浮条。隐藏工具仍可从“更多”打开，并显示对应参数；水印可重开既有内容、角度、间距与透明度并应用到原对象。
- **圆角裁剪**：选择“裁剪与导出圆角”，拖动二级菜单“圆角”滑块，0 恢复直角；截图中预览裁掉的四角，PNG 导出透明四角，工程保存并支持撤销。PNG 仍是矩形画布，圆角之外像素透明。

## 两套预制色与自定义颜色

颜色从用户附件中的 QQ 色板及标出的分析图色块取样，不声称是腾讯品牌色标准或规划规范色。

| 色板 | 色值 |
| --- | --- |
| 常用标注 | `#FB3838` `#FFC23D` `#94D23D` `#0099FF` `#FFFFFF` `#999999` `#000000` |
| 分析图 | `#85C4C2` `#EACD5D` `#E75A5D` `#59899F` `#96B759` `#ECC199` `#E15498` |

自定义面板包括饱和度／明度区域、色相条、原色与候选色预览、RGB、HEX 和原图取色。拖动只更新候选色，点击“应用”提交一次，支持输入校验和键盘微调。截图、详细属性、画板、文字便签、美化及水印的颜色入口共用面板；源代码中不再使用 `ColorDialog`。

## 验证

- 完整回归：**226 PASS / 0 FAIL**；涵盖组合选择、取消拖动、原子撤销、八点缩放、颜色联动、输入重编辑、注释切换、水印修改、圆角 PNG 与工程往返。
- 最后布局修改后，相关反馈回归：**30 PASS / 0 FAIL**。
- 可见原生窗口在 **125%（120 DPI）** 下验证鼠标 Shift 多选、HEX 编辑与应用、重复开关调色板 5 次、圆角预览和导出。界面截图来自自有合成底图。
- 本轮额外实屏快拖探针两次检测到测试窗口被遮挡，按保护条件中止截图，**未记为通过**。最终坐标、取消、撤销和重绘的自动化回归通过；前版实屏快拖记录不能当作本次重新实测。探针现在记录中止原因并退出，不再抛出未处理异常。
- 色板另有 100%／125%／150%／200% 的离屏布局样例。混合 DPI 双屏与真实用户长时间操作尚未验收，不将合成窗口测试描述为跨设备验证。
