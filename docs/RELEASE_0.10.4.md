# 0.10.4 逐点多边形

2026-11-10，开发预览版。

画笔的“自动闭合手绘线”改为“逐点多边形”：

- 单击逐个添加锚点。绘制中只显示已确定的线段和锚点，鼠标移动不会拉动首尾封口线，也不会生成拖动节点。
- 点击起点、双击最后一点、按 Enter，或点击二级工具条的完成按钮闭合。至少需要三个不共线的锚点。
- 右键、Backspace、Delete 或 Ctrl+Z 撤回上一锚点；Ctrl+Y 恢复，Esc 取消整次绘制。Shift 加点时按 45° 约束方向。
- 完成后保留同色半透明填充、移动、八点缩放、旋转与工程保存；闭合只产生一条撤销记录。
- 绘制期间 Enter 优先完成多边形，不会直接复制并退出截图。未完成的形状不会被悄悄丢在导出结果之外。

普通手绘、平滑笔画和自由曲线箭头继续保留。旧工程中的闭合手绘曲线按原样读取，不转换成折线。

本版 **304 项自动检查通过**，覆盖移动预览无封口线、逐点/双击闭合、锚点撤回与恢复、取消保留原重做分支、截图及文件编辑器的 Enter 路由、裁剪边界不抢占锚点、多边形变换与工程像素一致性、旧闭合曲线兼容和二级按钮。完成离屏绘制检查；不代表真实多屏和混合 DPI 已全面验收。

交付便携 ZIP、每用户 MSI、独立 EXE 与源码 ZIP，另核对包内 SHA-256、安装器结构及源码包独立重建。测试前先退出旧版托盘，再启动 0.10.4。
