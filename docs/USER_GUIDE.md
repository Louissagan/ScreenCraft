# ScreenCraft 0.9.4 开发预览使用说明

开始区域截图后，鼠标停留在控件或内容区可自动吸附；滚轮向上扩大、向下缩小候选范围，直接拖动仍手动框选。主工具栏“更多 → 工具栏显示与排序”调整顺序和显隐；隐藏工具仍可打开并调整参数。“裁剪与导出圆角”调整输出圆角，PNG 四角透明。

OCR 语言只能选择本机引擎支持的语言；取色的“RGB · 六位十六进制”输出如 #FF8040，“RGB · 三通道数值”输出如 rgb(255, 128, 64)。打开设置后仍可用全局截图快捷键；仅正在编辑快捷键输入框时录入组合键。


便携包解压后运行 `ScreenCraft.exe`。首次运行不启用开机自启。配置在旁边的 `Data/`；复制整个文件夹即可携带这些偏好。不要只复制 EXE。

0.5.0 起双击运行直接进入 Windows 右下角系统托盘，不再弹出主面板。左键托盘图标截图，右键打开 OCR、取色、长截图、图片编辑、贴图管理与设置；图标可能被 Windows 收进“隐藏的图标”。更换版本前，请先从旧版托盘选择“退出”。重复双击只提示已在运行。命令行 `ScreenCraft.exe --settings` 可直接打开已有实例的设置。

本版采用 Windows 原生 .NET Framework 4.8，Windows 11/较新 Windows 10 通常已经提供。无需 .NET SDK、Visual Studio、Python 或联网服务。干净机器兼容性仍待验收。

0.5.1 设置使用 Windows 标准右上角窗口按钮；关闭设置继续留在托盘。托盘右键菜单显示版本号、功能图标和当前配置热键，点击相应项执行。贴图右键与截图“更多”菜单采用同一套样式。

0.6.0 的取色格式用统一样式的下拉选择器。点击展开或使用 Alt+Down/F4，方向键/Home/End 也可直接选择，Tab 切到下一项。新配置与“恢复默认”使用 RGB；已保存的 HEX/HSL 保留。HEX 大写选项仅在 HEX 格式下可用。应用文件、任务栏、托盘及设置/OCR/编辑/贴图窗口使用相同蓝色截图图标；更换版本请先退出旧进程。

框选后在原位置直接标注。0.5.0 起窗口识别与编辑阶段统一使用醒目的蓝白边框，选区外默认压暗 70%；在设置“截图”中可调 45–85%。下方图标条选择工具，第二条修改当前工具属性；两条作为一组优先放下方，不足时整体上移，属性保持在主条下方。设置可改优先位置。八个白色蓝边控制点调整范围，拖动尺寸标签移动范围；未选中标注时方向键移动截图范围。范围修改可撤销，Enter 完成复制，P 贴图，Esc 取消当前操作或退出本次截图，不退出后台程序。

点选图形后可拖动、拖控制点调整大小。浮条的滑块可调线宽/字号/马赛克块大小，滚轮细调；属性图标支持直角/圆角、填充及线型。点击“详细标注属性”图标展开精确属性面板，保留完整线型、填充透明度、位置、序号及说明；几何填充色跟随所选颜色。序号可改号码并附说明，云线画好后进入文字输入；双击文字、序号或云线再次输入。Enter 提交文字，Shift+Enter 换行，输入时工具键不触发。

钉图保留选区原图和标注对象。右键可重新编辑、复制、保存、OCR、原始大小、置顶、透明度、鼠标穿透、缩略或关闭。普通滚轮围绕指针等比缩放，右下角的小把手可拖动等比缩放；Ctrl++ / Ctrl+- 也可缩放，Ctrl+0 恢复 100%。S 缩略/恢复，Z 在 100% 与前一比例之间切换。Ctrl+滚轮按 5% 调透明度（20%~100%）。独立关闭此图不关闭其他图。鼠标穿透后从托盘“贴图管理”恢复。

PNG 是扁平结果，实色遮盖会写进导出像素。`.sccraft` 是可编辑工程，保留原图；需要继续编辑时使用，分享图片时选择 PNG。

0.9.3：矩形圆角可用第二条工具栏滑块调整。文字及三种注释共用“所选颜色作底色＋白字”模式，仅提供一个颜色入口；点大小与引线粗细联动。Shift／Ctrl 单击增减选中对象，Ctrl+A 全选；组合改色、移动、缩放、删除、复制与撤销。矩形、文本框及组合选框支持四角及四边中点，直线／箭头保留端点和曲线控制点。

新截图的可编辑工程只保留选区底图，不带出选区外冻结桌面；工具条和变暗遮罩也不会导出。本地文件编辑保留其原文件底图以继续编辑。

本地 OCR 可从全局键、主界面、编辑器和贴图右键打开。结果窗口列出已安装语言，可选择、编辑、复制结果或取消/重试。设置中的 `auto` 优先简中、再英文；可指定 `zh-Hans` / `en`。缺包时程序说明应检查的 Windows 语言功能，不自动下载、安装或调用云服务。长图会分带识别；结果需要校对，某些短行可能漏识别（OCR-001）。

取色热键冻结屏幕，放大镜内单击或 Enter 复制颜色；Esc/右键取消。截图态按 C 打开放大镜。编辑器 C 取原图像素，忽略标注层；Esc 只取消此次取色。格式可在设置中选 HEX、RGB、HSL 和 HEX 大小写。

滚动长截图先框选实际滚动区域，然后手动向下滚动。边缘显示预览和高度；Enter/完成结束，取消丢弃本次。尚未产生长图时，首次完成提示，再次确认可保留普通截图。有已拼接内容时首次 Esc 提示，再按才丢弃，均不退出程序。自动滚动须主动点击 Auto，移动鼠标会暂停。采集中隐藏本软件原有窗口，结束恢复。达到 30000 行或 4000 万像素会停止并说明仅有部分页面；编辑器可“分段导出 PNG”（每段 4000 行，末段保留剩余行，写入新子目录），未捕获的页面需重新选区采集。不要跨越无重叠内容快速跳页。

设置采用顶部图标分区：常规、截图、快捷键、工具栏、OCR 与取色、关于。在“快捷键”中点击对应栏，直接按 Ctrl/Alt/Shift 加一个按键录入。Delete / Backspace 或“清除”禁用，Esc 恢复进入该栏时的值，Tab / Shift+Tab 切栏。点击“保存并应用”后生效，冲突保留旧键。版本号及配置位置在“关于”。“常规”的自启开关只修改当前用户 Run 项；默认关闭，恢复默认不擅自改变自启开关。已有标准 ScreenCraft 自启项指向旧版或已移动的位置时，新版启动会更新为当前路径；原本关闭自启时不会自动开启。

“工具栏”页可拖动重排或使用上移/下移，取消勾选隐藏工具；选中工具后直接按一个字母修改工具键，P/C 保留用于贴图/取色。点击底部“保存并应用”生效。隐藏工具仍可从“更多”或其工具键打开，下一次截图使用保存后的配置。

关闭设置会保留托盘，托盘“退出”才结束程序及全部贴图。本版还没有完成真实桌面验收，具体边界见 KNOWN_LIMITATIONS.md。

## 0.8 新增操作

- 一级标注工具下面切换点备注、云线、序号。点备注的小目标点、引线文字牌可独立拖动；序号默认直接标在点击位置，另可主动选择引线数字牌。输入增长至指定宽度自动换行；拖说明框角点或宽度滑块调整，自动扩展开关恢复自然增长。
- 画笔二级条切换原始/平滑/自由曲线箭头；“逐点多边形”改为单击增加锚点，点击起点、双击或 Enter 闭合；右键/Backspace/Ctrl+Z 撤回锚点，Ctrl+Y 恢复，Esc 取消。绘制中只显示已确定的边，不拉动封口线；完成后可使用同色填充、移动、八点缩放和旋转。按 Shift 绘制横竖线。箭头二级条可选白边实心模式。
- 选中标注后，拖动选框上方圆点旋转，Shift 吸附到 15°；二级条可顺时针旋转 90°，详细属性可输入角度。支持多选一起旋转。文字编辑期间横排输入，完成后保留角度。
- 调整层级：Ctrl+] 前移、Ctrl+[ 后移；Ctrl+Shift+] 置顶、Ctrl+Shift+[ 置底。截图、图片编辑器及画板共用这些快捷键。
- 未选标注时方向键移动范围 1px，Shift 为 10px；Ctrl 调整右/下边，Alt 调整左/上边。贴图获得焦点后方向键也按 1/10px 移动。输入文字和调整滑块时保留各自键盘行为。
- 马赛克二级条可切柔化模糊或彩点遮盖。更多菜单提供聚光灯、文字水印和复制并继续标注（Ctrl+Shift+Enter）。文字水印可调角度/间距/字号/透明度；还没有图片水印。
- 托盘文字备忘打开可编辑内容、字体、字号、边距、宽度与前景/背景的面板，再钉为独立图像。贴剪贴板时若只有文字，也进入此面板；钉出的是图片，后续修改文字需重新生成。
- 设置截图页可调压暗百分比、边框粗细/颜色、十字线和工具栏优先位置。常规页可关闭启动系统通知。启动和重复打开都使用 Windows 通知，显示位置与持续时间由系统管理。
- 调色精简为 6 个常用色和 2 个规划参考色（居住黄 #FEDD78、绿地绿 #0D7B3E），仍可输入 HEX 或从原图取色。矩形、椭圆、云线改色时填充跟随描边，保留透明度；说明文字可在输入时或详细属性中单独改色。浮条磨砂取自冻结截图，不跟随桌面实时更新。

自动化与真实可见窗口的验证范围见 [0.9.1 界面审查](UI_UX_REVIEW_0.9.1.md) 和 [0.9.2 反馈修正](UI_FEEDBACK_0.9.2.md)。

## 0.9 日常工作流

设置新增贴图页；截图页可选默认工具、包含光标、完成动作、自动保存目录与文件名模板、历史开关和保留条数。新增当前屏全屏、当前窗口、重复区域、全部贴图显隐、打开画板的热键默认留空；在快捷键页主动录入后生效。

完成默认仍只复制。复制并自动保存和仅保存可选；自动保存目录默认显示并使用当前系统桌面，清空也使用桌面；中文用户名、空格和桌面重定向均按系统实际路径处理。自定义目录仍可指定，支持相对数据目录的路径。模板支持 {date}、{time}、{id}，重名加后缀。历史默认关闭，启用后从托盘打开历史面板；删除/清理只影响自有副本。

贴图 Ctrl+R 顺时针旋转 90°，Ctrl+H 水平翻转，Ctrl+J 垂直翻转，右键可重置。方向键 1px、Shift 10px。吸附按图片实际边缘而非透明阴影计算，Alt 拖动临时关闭。贴图页可交换普通/Ctrl 滚轮功能、反向滚轮，以及默认透明度/缩放、边框/圆角/阴影。Ctrl 按住拖动贴图可拖出 PNG 文件；真实外部接收尚未验收。

托盘的隐藏/恢复全部贴图与单张右键隐藏互相配合；贴图管理提供预览、恢复鼠标交互、旋转、隐藏、关闭。旋转不破坏原标注，保存 sccraft 后重新创建贴图保留方向；编辑时以原图坐标操作。

托盘打开拼图画板；可添加本地图片、粘贴、加入当前贴图。左键选中/拖动，右下角拖动等比缩放，右键拖动画布，滚轮缩放视图；Alt 临时取消吸附。方向键移动、Ctrl+D 复制、Delete 删除、Ctrl+Z/Y 撤销/重做。工具条可改层级、旋转、背景、适应视图或 100%。保存 scboard 工程继续编辑，导出 PNG 覆盖全部内容；选图可独立贴屏。关闭未保存画板会提醒。

截图更多菜单或图片编辑器的美化按钮打开纯色/渐变、边距、圆角、采样边框、阴影和比例预览；应用可撤销，工程保留原图。图片再编辑采用共享图标工具条，模式与字号/线宽位于下方，精确属性在右侧。

关于页可导入/导出配置；导入只填充待保存值，保存并应用才注册热键。导出不携带自启授权，导入不改变当前机器的自启开关。MSI/便携安装、升级和卸载见 INSTALLATION.md。

## 0.10.3 调色与线宽

色盘分常用标注 16 色、分析图 12 色；右上角彩色按钮打开色相、RGB、HEX 自定义颜色。线宽默认 4px，快捷滑块范围 1–24px，旁边的数字框支持小数输入。Enter 确认数值后回到画布，Esc 放弃待输入值。旧工程中超过常用范围的线宽保持原值。字号、马赛克和标记大小继续使用各自的范围。
