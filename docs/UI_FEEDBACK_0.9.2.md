# 0.9.2 用户反馈修正

2026-11-05。针对本轮四项反馈；前轮全界面审查与快拖修复见 [0.9.1 记录](UI_UX_REVIEW_0.9.1.md)。用户明确“右下角模糊”指启动提示。

## 行为修正

- **填充跟随轮廓**：旧版描边与填充分别存储，换色只更新描边，导致玫红底残留。创建矩形、椭圆、云线、点备注时按当前颜色生成填充；修改描边或启用填充同步色相，保留透明度及撤销/重做。默认截图填充约 24% 不透明度。详细属性的几何填充色注明“跟随描边”，不再提供互相矛盾的选色入口。旧工程载入不擅自重写已有颜色；重新改色/启用填充时同步。
- **简化色板**：24 色减为 8 色：红、蓝、紫、黑、白、灰，以及居住黄、绿地绿。保留自定义 HEX、系统选色、原图取色。云线未输入文字时，快捷色板修改轮廓和填充；正在输入说明时可独立修改文字。
- **点上序号**：新建序号默认在点击处绘制圆形数字，编号与点共同移动，不自动生成远处数字牌。引线数字牌仍可主动选择，旧工程的显式样式保留。
- **启动提示**：旧窗口固定 380×92，正文用默认 GDI+ 字体栅格化，且末段全窗透明。现在按所在屏幕 DPI 同步布局、像素字体与图标，文字使用 ClearType；保留短距离上浮、非激活与自动消失，整个显示期间保持不透明。

## 验证范围

- **212 PASS / 0 FAIL**：[回归结果](evidence/automated/feedback-0.9.2/automation.csv)。新增覆盖透明填充的真实渲染像素、换色与透明度、撤销/重做/保存、云线文字与轮廓角色、点上序号和无中间鼠标移动消息时的最终落点。
- **启动提示实际窗口**：同一显示器，原生 DPI 为 120（125%）。旧版 380×92，新版 475×115。分别抓取 0、90、180、2500 ms 的本进程提示窗口客户区。新版四张 PNG 的 SHA-256 完全相同（`FF15E0CB7F976F46EAFA578F4CB184B099DCE5381F7D210AB567BA277ABA9510`），文字在动画各阶段保持相同像素。旧版 2500 ms 不透明度约 0.773，新版为 1。没有截取用户文件内容，也没有替换正在运行的托盘进程。
- **离屏缩放**：100%、125%、150%、200% 的完整提示图像与布局检查通过；长快捷键可换行。后两种比例不是实际显示器测试。
- **快拖实际窗口复测**：合成底图、定向原生鼠标消息，120 次移动耗时 85 ms；最终选区 690×240，与松手坐标相符。拖动中及松手后对比强制重绘均为 0 个差异像素：[探针记录](evidence/automated/feedback-0.9.2/native-drag.txt)。不据此宣称混合 DPI 双屏、所有刷新率或用户原始叠框条件已全部验证。
