# 0.4.0 原位截图、参考界面与贴图等比缩放

2026-11-04。用户明确指定：截图应保留冻结背景、选区原位和附近的工具条，并以 1Capture 的图标和界面为基准；贴图支持等比放大缩小。路线采用公开界面/文档的行为复刻，继续复用实际构建评估过的 Stackshot Windows 核心。本轮没有逆向或运行 1Capture 的 macOS 二进制。

## 实际代码与行为

- `AnnotationCapturePicker.cs` 在原冻结 DIB 释放前交接原始桌面位图；截图选区松手后直接进入 `CaptureOverlay`，取消多余的大编辑窗口步骤。捕获期间原有自家窗口持续隐藏，结束后恢复。
- `InPlaceCanvas.cs` 使相同 Canvas/Shape/Painter 引擎以物理像素 1:1 处理选区。变暗、边框、工具条属于界面层；复制/PNG/工程/贴图只读取选区及标注。
- `CaptureVisuals.cs` 与 `CaptureOverlay.cs` 使用几何图标、浅色圆角浮条、蓝色选中、上下文属性和滑块。依据官方工具条示例及用户照片，保留 Windows 的中文提示、Ctrl 与原有输入习惯。真实桌面视觉仍未验收。
- `ToolbarSettings.cs` 提供工具排序/隐藏、单键配置、验证/持久化；隐藏工具仍有更多入口。详细属性面板继续复用 AnnotationInspector，保留原功能。
- `PinScaling.cs` 让滚轮、右下角拖动和 Ctrl +/- 使用同一个缩放标量；图像尺寸按同一比例取整，S/Z 支持缩略和原始大小切换，Ctrl 滚轮独立调整透明度。
- 新截图工程只保存选区原图，平移标注坐标并保留 ID、图形属性和说明。马赛克固定块大小写入工程；裁切边缘先隔离采样区域，避免重渲染后像素变化或采到选区外图像。

## 失败闭环

- 首轮贴图交接夹具对无 AccessibleName 的按钮调用 StartsWith，修正夹具空值判断；不是产品崩溃。
- 新增“裁切到马赛克边缘”像素对照失败，发现块大小随源图尺寸变化且降采样可能取到范围外像素。块大小持久化、明确选区裁切及隔离区域采样后，同一边界用例逐像素 PASS。
- 源图固定比例后取消 Canvas 自身缩放/平移，避免截图与冻结桌面错位；贴图缩放仍独立作用于显示尺寸，不改变原图或标注模型。
