# 架构

运行时实现分为 `src/Core` 与 `src/App`。0.10 的替换范围、来源记录和验证方法见 [内核重写](CORE_REWRITE.md)。

- **Core**：采集、选区、几何、渲染、画布输入、贴图、拼接、OCR 调用和背景合成。
- **App**：编辑界面、标注样式、智能控件识别、设置、托盘、热键事务、历史、画板和导出。
- **Tests**：同一生产代码上的合成输入、隐藏 HWND 绘制、资源所有权及文件兼容检查。
- **Tools**：编译、来源边界检查、安装包构建及可选原生验收探针。

截图先冻结虚拟桌面，再选择区域和编辑。画布以图像坐标保存标注，屏幕坐标只用于显示与输入转换。松手提交最后坐标，取消或丢失捕获恢复操作前状态。

`.sccraft` 保存底图和 JSON 标注；PNG 只包含合成结果。贴图一图一 HWND，持有独立文档和显示状态。缩放、透明度和旋转不改源图。

OCR 在 MTA 工作线程调用本机识别功能。全局热键由 `TransactionalHotkeys` 注册，新绑定成功后才释放旧绑定。设置窗口只在快捷键录入控件获得焦点时拦截录入。

构建使用系统 .NET Framework 4.8 编译器，无 NuGet 依赖。绘制使用 WinForms/GDI+；WindowsBase/UI Automation 用于系统控件边界识别。MSI 首次构建另外取得经哈希校验的 WiX 工具，应用运行时不下载依赖。
