# 0.10.1 截图闪烁修复

2026-11-09。针对 Alt+A 等截图热键唤起、框选松手交接时的闪烁回归。

## 与 0.9.4 对照

检查的是本地保留的 0.9.4 源码及成品，没有重新引入旧运行时模块。

| 时序 | 0.9.4 做法 | 0.10.0 回归 | 0.10.1 修复 |
|---|---|---|---|
| 首帧 | 构造阶段先合成完整缓冲区 | 显示后的绘制事件才合成 | `PreparedCaptureFrame` 在显示前完成合成 |
| 重绘 | 已完成画面直接复制到窗口 | 完整场景进入 WinForms 延迟重绘 | `WM_PAINT` 只复制完整帧，状态变化即时呈现 |
| 松手 | 拖动选区保留到接受结果 | 清掉拖动状态后临时退回悬停范围 | 交接期间固定最终选区，不再回退 |
| 标注交接 | 旧浮层留在模态窗口后面 | 同样存在模态返回路径 | 新窗口及子窗口准备完、绘制并同步后，再隐藏并释放旧浮层 |

截图浮层使用物理像素边界、不参与自动缩放；只关闭这些窗口自身的 DWM 进出动画，不改用户的系统动画设置。原有截图快捷键及截图前隐藏/恢复本程序窗口的规则保持原样。

## 验证

- **262 项自动检查通过**，新增首帧早于 HWND 创建、绘制不再合成、交接顺序、最终选区保留及 Alt+A 编解码检查。
- 自有 800×500 实窗口探针完成 **3 次交接、113 帧采样、0 个异常空白色帧**；标注返回后旧框选窗口可见次数为 **0**。
- 原生探针仅截取被本进程窗口完整覆盖的测试区域，输入只发给自己的 HWND。它没有操作用户实际 Alt+A、剪贴板或配置。
- 测试进程在创建合成窗口前替换自身的截图排除边界，避免显示亲和性切换把抓取排除结果误认为可见闪屏。旧 0.9.4 没有这个测试边界，故只比较其模态生命周期，不报告其像素闪烁率；早期干扰样本不作为结论。

本次实窗口采样不能代替用户真实全屏、多显示器及混合 DPI 验收。程序为 0.10.1 开发预览，未重新生成 MSI 或便携包；先退出托盘旧版，再运行 `bin/Release/ScreenCraft.exe`。

实现：`src/Core/PreparedCaptureFrame.cs`、`src/Core/RegionSelectionWindow.cs`、`src/App/CaptureHandoff.cs`。

Windows 的窗口级动画参数参见 [Microsoft DWM 文档](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute)。
