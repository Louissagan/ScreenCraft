# 0.8.0 调色报错、属性条与启动反馈

日期：2026-11-05。依据用户的截图调色崩溃、设置下拉报错、属性条上下分离、启动过于静默及选框不清晰反馈修复。未操作用户桌面、显示测试窗口或注册真实热键/启动项。

## 菜单生命周期

两个报错都指向已释放的 `StyledMenu`。旧设置选择器与截图调色/更多菜单在 `Closed` 回调内同步 `Dispose`；原生菜单尚在完成点击、焦点或自动关闭流程时，对象已被释放。

先将设置的同一生产关闭回调提取为可隐藏执行的入口，保留旧同步释放逻辑：新回归立即失败（`popup-lifecycle-before-fix.txt`）。改为由所属输入控件/截图编辑器持有并复用菜单，仅在所属对象释放时销毁后，通过 40 次选择、关闭回调和再次准备打开的检查。截图椭圆绘制后通过真实色块按钮回调换色、关闭、重开 40 次，保持同一菜单 HWND；保留填充、撤销和输入中的说明文字。这里重放的是隐藏 HWND/生产回调；没有冒充真实鼠标点击展开菜单。

## 调色与布局

调色面板改为紧凑分组：8 个常用色、8 个建筑材料/环境分析建议色、8 个分区对比色。保留独立 HEX 输入与非法输入反馈、更多颜色和原图取色。颜色作用于当前描边或文字角色，不误改说明圆点。

分区对比采用 [ColorBrewer Set2](https://colorbrewer2.org/?type=qualitative&scheme=Set2&n=8)，色值核对 [官方源码](https://github.com/axismaps/colorbrewer/blob/master/colorbrewer_schemes.js)，按 [Apache 2.0](https://github.com/axismaps/colorbrewer/blob/master/LICENCE.txt) 随包保留许可与归属。建筑分析一组是项目选配的砖红、赭黄、砂岩、草木、深绿、水蓝、蓝灰和炭灰；不是任何法规或统一专业配色标准。

主工具与属性行按总高度一起定位，属性行始终位于主工具栏下方，间隔 6px。默认优先放选区下方，空间不足则整体放上方；上下均不够时整体限制在工作区内，可以覆盖选区一部分，不再拆到两边。尺寸标签避开两行工具条。旧回归夹具只为一行留空间，更新为上方能容纳完整组合的场景，保留“完整组合位于选区外”的断言；同时另测四角和两种位置偏好。

## 设置与启动

截图设置中的静态说明行改为操作控件：压暗百分比可拖滑块或输入数字，边框可选 2/4/6px、蓝/青绿/橙，工具条可选优先上方/下方。默认边框 4px；增加实色外衬、白色细线和内侧强调线。屏幕边缘裁掉外框时，内侧强调色仍保留。识别窗口重绘区域随边框外扩大小更新，防止加粗后留旧边线。

新增右下角任务栏上方的“ScreenCraft 已启动”提示，短距离上浮、约 2.7 秒后结束；不激活、不占任务栏、不打开设置。重复启动提示“已在运行”。常规设置可关闭提示。它使用主显示器工作区；自启命令仍维持当前用户级方式，测试未改真实注册表。
