# 0.9.0 日常标注、贴图与用户级安装

日期：2026-11-05。继续核对 1Capture 中文更新日志（再次 HTTPS 读取 HTTP 200，291021 字符，可见 19 版本，最新 1.12.0）。录屏后置；没有操作用户桌面、显示应用窗口、读取真实截图/剪贴板或注册真实热键/启动项。

## 实际实现

1. 当前屏全屏、当前窗口、重复上次区域，进入同一原位编辑器。范围基于冻结桌面物理坐标，失效区域切回手动框选。默认工具和包含系统光标可设置；10 个全局动作独立可配，新增动作默认禁用。
2. 贴图视图 90° 旋转、水平/垂直翻转与重置；复制和 PNG 输出反映方向，原图/标注保持独立。sccraft 保存方向元数据，重新贴屏后恢复；重新编辑使用原图坐标，再应用到贴图。通用对象任意角度旋转没有冒充完成。
3. 贴图隐藏/恢复全部、隐藏单张、托盘恢复鼠标穿透、物理边缘/相邻图片吸附（Alt 暂停）、缩放/透明度滚轮交换、反向滚轮、默认透明度/缩放、边框色/宽/圆角/阴影。配置改外观同步到现有图，新图初始大小/透明度只作用新图。
4. Ctrl 按住拖动贴图时准备真实 PNG 文件并调用 Windows OLE 拖出；过期自有中转 PNG 下次清理，不删除无关文件。自动化验证了数据对象和 PNG，不代表微信/Office/资源管理器实际接收已通过。
5. 设置导入/导出有版本、范围、工具栏和重复键验证，保留当前机器自启授权，导入后需保存才应用。启动时只读核对实际自启命令，便携目录变化时提示，不自动重写。
6. 复制并退出/复制并自动保存/仅自动保存，目录、日期/时间/ID 文件名模板与重名避让；失败保留编辑器。历史默认关闭，启用后按条数保留自有副本，可预览、复制、贴图、编辑、删除与清理。用户手动保存目录独立。
7. 独立拼图画板：最多 100 张（含撤销源图合计 6400 万像素），按比例缩放、拖动、方向键、90° 旋转、层级、复制/删除、撤销/重做，边缘/中心吸附与辅助线、Alt 暂停，视图平移/缩放/适应内容、透明/自定义背景。scboard ZIP 自包含资源；导出全部内容边界，负坐标和视口外不丢失。可从选图创建独立贴图，关闭有未保存提醒。
8. 美化接通底座 Backdrop：纯色、12 种渐变、边距、圆角、采样边框、阴影、比例，实时预览、应用/撤销和工程往返。原位编辑保留物理位置，美化反映在导出/贴图及面板预览。桌面/自选壁纸库尚未接通。
9. 图片编辑工具条、贴图管理和历史界面使用共享几何图标/白卡控件；本地编辑的模式在工具条下方切换，精确属性保留右侧。没有声称本地编辑器与截图浮条逐像素相同。

## 用户级安装包

复用 Stackshot 的 WiX 打包路线，构建固定 SHA-256 的 WiX 3.14.1；编译器只解压到 .tools，不在用户系统安装。

- 产物 ScreenCraft-Setup-PerUser-win-x64.msi；安装到 LocalAppData/Programs/ScreenCraft、当前用户开始菜单、HKCU 安装信息。
- Package 为 perUser / limited，拒绝 ALLUSERS 覆盖；MSI Summary WordCount 的 LUA 位启用。注册表写入表只含 HKCU；Windows 版本检查只读 HKLM。
- 默认不启动应用、不启用自启、不删除用户数据；不强杀进程。
- 卸载请求通过 SID 与安装路径哈希专属事件通知对应实例，等待正常退出；便携路径不匹配，不受影响。未保存画板可以取消关闭，超时阻止卸载而不强杀。
- 清理启动项只删除命令精确指向当前已安装 EXE 的 ScreenCraft 项。默认保留设置、历史及用户图片；REMOVEUSERDATA=1 仅清理生成的历史缓存，保留手动保存文件。
- 升级使用稳定 UpgradeCode，阻止降级；安装/菜单路径从 HKCU 记住，不靠默认目录猜测。

## 源码独立重建发现的后续修复

第一次源码 ZIP 在更深的目录重建时，历史/中转 PNG 的 GDI+ 文件名保存出现长路径失败（198 PASS / 3 FAIL），保留 package-long-path-before-fix-0.9.0.txt。补充回归又复现了多行 OwnerDraw 的 Clear 擦掉前行，以及超过 MAX_PATH 的目录创建问题。

当前图片读写使用文件流，FilePaths 将长路径规范化后使用 Windows 扩展路径；运行时配置启用对应 .NET 路径行为，未更改系统长路径注册表策略。PNG、配置、sccraft 和 scboard 都在超过 MAX_PATH 的中文路径实际读写通过。OwnerDraw 改为仅填充当前行矩形，三行文本同时保留；修复前后日志和 history-three-rows.png 均保留。新增这两项后总计 203 PASS / 0 FAIL。
